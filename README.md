# Terramoda Web Demo

Demo pública de Terramoda, tienda de moda pre loved en Encarnación.

## Demo en línea

https://terramoda-enc-demo.cometbook5.chatgpt.site/

## Incluye

- Catálogo visual con filtros.
- Consultas por WhatsApp.
- Ubicación y horarios.
- Panel de inventario para demostración.
- Carga de prendas, fotos, precios, talles y stock.
- Ajuste de unidades, ocultar, archivar y restaurar prendas.

## Panel de demostración

https://terramoda-enc-demo.cometbook5.chatgpt.site/demo

Los datos de la ruta `/demo` se guardan únicamente en el navegador donde se prueba, porque es una demo pública. La versión comercial debe usar autenticación del propietario y una base de datos persistente.

## Estado del proyecto

Este repositorio fue creado para alojar el código fuente de la demo. La carga del código completo se completará cuando el entorno de trabajo vuelva a estar conectado.
